POCKETSMART AI – SMART BUDGET & RECOMMENDATION ASSISTANT

PHASE 2: REQUIREMENT ANALYSIS

Functional Requirements:

- User registration and login
- User enters income or budget
- AI generates budget-based recommendations
- Home Interior budget planner
- Party budget planner
- Jewelry budget planner
- Upload outfit image for Jewelry Planner
- View recommendation history
- User logout

Non-Functional Requirements:

- Fast response time
- Application should not crash when Gemini API is unavailable
- Local fallback engine should provide recommendations
- Secure authentication
- Simple and user-friendly interface

Technical Requirements:

- Python
- FastAPI
- Jinja2
- HTML, CSS and JavaScript
- SQLite
- Gemini API
- JWT / Session-based authentication
- requirements.txt
